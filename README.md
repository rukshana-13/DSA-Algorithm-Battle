ALGORITHM BATTLE – WHICH DATA STRUCTURE WINS?

Student Record Search System

Course: Data Structures and Algorithms
Language: C
Application: Student Record Management

1. Problem Statement

The project aims to store and search student records efficiently using three different data structures.

2. Data Structures Used

* Binary Search Tree (BST)
* AVL Tree
* Hashing with Linear Probing

3. Operations

* Insertion
* Searching
* Inorder Traversal
* Tree Height Calculation
* Collision Handling using Linear Probing

4. Dataset

The experiment uses 30 unique student records with Student ID and Name.

5. Experimental Analysis

The three data structures are tested using the same dataset.

The following parameters are compared:

* Successful search comparisons
* Unsuccessful search comparisons
* Insertion observations
* Tree height
* Number of hash collisions

6. Conclusion

BST provides ordered storage, AVL maintains balanced searching performance, and Hashing offers efficient average-case searching.

The final recommendation is based on the actual experimental results.
